## 🧠 About This Project
An interactive educational website that makes **quantum computing concepts** accessible to everyone. No PhD required!

**What you'll learn:**
- 🎲 Qubits vs. classical bits
- 🔗 Quantum entanglement ("spooky action at a distance")
- 🐈 Schrödinger's cat (and why it's both dead AND alive)
- 🔐 How quantum cryptography creates unhackable encryption

## 🎮 Interactive Features
- **Qubit Simulator** – Apply Hadamard gates, measure qubits, and watch the Bloch sphere react
- **Random Quantum Facts** – Discover mind-blowing quantum physics trivia
- **Responsive Design** – Works on phones, tablets, and desktops
